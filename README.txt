YORU — папка для публикации сайта

Файлы:
- index.html — главная страница сайта (обязательно оставьте это имя)
- yoru-favicon.svg — значок вкладки браузера
- yoru-logo.svg — фирменный логотип

ПУБЛИКАЦИЯ ЧЕРЕЗ NETLIFY
1. Распакуйте архив в отдельную папку.
2. Откройте https://app.netlify.com/drop
3. Войдите/создайте аккаунт Netlify, если хотите сохранить сайт и потом обновлять его.
4. Перетащите на страницу Netlify распакованную папку YORU_PublishReady (либо выберите её через Choose folder).
5. Дождитесь публикации и скопируйте созданную ссылку *.netlify.app.

ОБНОВЛЕНИЕ САЙТА
Измените index.html локально, затем откройте панель своего сайта в Netlify и перетащите новую папку с файлами в область ручного деплоя на странице Deploys.

ВАЖНО
Это статический сайт. Каталог и перевод используют внешние API из браузера и требуют интернет. В этом пакете нет собственного backend-сервера и нет активированной авторизации аккаунтов. Публичная ссылка делает страницу доступной другим людям. Перед крупным запуском проверьте доступность внешних API, контентные права и ссылки социальных сетей.
