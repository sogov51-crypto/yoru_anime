YORU — личная аниме-библиотека

СТРУКТУРА

- index.html — разметка страницы и порядок подключения скриптов.
- css/styles.css — оформление и адаптация под разные экраны.
- js/shared.js — общее состояние и функции интерфейса.
- js/providers.js — запросы к AniList, Jikan и Shikimori.
- js/catalog.js, catalog-cache.js, anime-data.js — каталог, его кэш в IndexedDB и преобразование данных API.
- js/search.js, categories.js, rankings.js, hero.js — поиск, фильтры, рейтинги и главный баннер.
- js/anime-details.js, episodes.js, localization.js — карточка тайтла, эпизоды и перевод.
- js/profile.js, community.js, settings.js, navigation.js — профиль, сообщество, настройки и навигация.
- js/app.js — запуск приложения после загрузки остальных скриптов.

JavaScript разделён по задачам. Классические скрипты в index.html используют
общее состояние и поддерживают существующие обработчики в разметке.

ЗАПУСК В ЛОКАЛЬНОЙ СЕТИ

1. В PowerShell перейдите в папку YORU_PublishReady.
2. Выполните ipconfig и найдите IPv4-адрес Ethernet или Wi-Fi, подключённого к домашнему роутеру.
3. Запустите сервер через Python 3, подставив этот адрес вместо 192.168.1.10.

   python -m http.server 8000 --bind 192.168.1.10

4. Подключите телефон к Wi-Fi того же роутера и откройте адрес компьютера с портом 8000 (например, http://192.168.1.10:8000/).
5. Чтобы остановить сервер, нажмите Ctrl+C в окне, где запустили команду.

Если страница открывается на компьютере, а на телефоне нет, проверьте входящие
подключения для используемой версии Python в брандмауэре Windows и изоляцию
устройств в гостевой сети Wi-Fi.

ПУБЛИКАЦИЯ ЧЕРЕЗ NETLIFY

Загрузите всю папку YORU_PublishReady через https://app.netlify.com/drop.
При обновлении сайта загрузите папку снова через раздел Deploys.

Каталог и перевод обращаются к внешним API из браузера и требуют интернет.
Профиль, избранное, прогресс и данные сообщества хранятся в браузере каждого
устройства. Для синхронизации между устройствами понадобится общий сервер
с хранением данных и авторизацией.
